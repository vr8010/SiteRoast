# 🔥 SiteRoast

> AI-Powered Website Analyzer & Roast Tool

SiteRoast is a fun yet practical web application that analyzes websites and provides:
- 🎨 UI/UX feedback
- ⚡ Performance observations
- 🔍 SEO suggestions
- 🛡️ Security insights
- 😂 Funny AI-generated website roasts

Perfect for developers, designers, freelancers, and cybersecurity enthusiasts who want quick website reviews with personality.

---

## 🚀 Features

- 🌐 Analyze any public website URL
- 🤖 AI-generated website roast
- 🎨 UI/UX improvement suggestions
- ⚡ Performance & responsiveness feedback
- 🔍 SEO observations
- 🛡️ Basic security checks
- 📱 Responsive modern interface
- 🌙 Clean and user-friendly design
