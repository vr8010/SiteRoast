SiteRoast 🔥
AI-Powered Website Analysis & Roast Tool

SiteRoast is a fun yet practical web application that analyzes websites and provides instant feedback, performance insights, UI/UX suggestions, SEO observations, and humorous “roasts” of websites.

It is designed for developers, designers, and cybersecurity enthusiasts who want quick and engaging website reviews.

🚀 Features
🌐 Analyze any website URL
🎨 UI/UX feedback and design roast
⚡ Performance analysis and observations
🔍 Basic SEO checks
📱 Responsive design evaluation
😂 AI-generated website roasts
🛡️ Security and best-practice observations
📊 Clean and interactive user interface

⚙️ Installation
1️⃣ Clone the Repository
git clone https://github.com/vr8010/SiteRoast.git
cd SiteRoast
2️⃣ Create a Virtual Environment (Optional)
python -m venv venv
3️⃣ Activate the Virtual Environment
Windows
venv\Scripts\activate
Linux / macOS
source venv/bin/activate
4️⃣ Install Dependencies
pip install -r requirements.txt
▶️ Run the Project
python app.py

Open your browser and visit:

http://127.0.0.1:5000
