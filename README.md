SiteRoast 🔥
AI-Powered Website Analysis & Roast Tool

SiteRoast is a fun yet practical web application that analyzes websites and gives instant feedback, performance insights, UI/UX suggestions, SEO observations, and “roasts” websites in an entertaining way.
Perfect for developers, designers, and cybersecurity enthusiasts who want quick website reviews with style.

🚀 Features
🌐 Analyze any website URL
🎨 UI/UX feedback and design roast
⚡ Performance observations
🔍 Basic SEO analysis
📱 Responsive layout checking
😂 Fun AI-generated website roast
🛡️ Security & best-practice observations
📊 Clean and interactive frontend

⚙️ Installation
1️⃣ Clone the Repository
git clone https://github.com/vr8010/SiteRoast.git
cd SiteRoast
2️⃣ Create Virtual Environment (Optional)
python -m venv venv
3️⃣ Activate Environment
Windows
venv\Scripts\activate
Linux / macOS
source venv/bin/activate
4️⃣ Install Dependencies
pip install -r requirements.txt
▶️ Run the Project
python app.py

Open browser:

http://127.0.0.1:5000
